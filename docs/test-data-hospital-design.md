## 五、插入顺序（你确认后执行）

1. **sys_dept**：按上表 id 1～10 插入（若自增从 1 开始则 id 与表一致）。  
2. **duty_shift**：7 条班次（3 行政 + 3 值班 + 1 领导带班），code 全局唯一。  
3. **sys_user**：14 条用户；admin 的 dept_id=1，其余按上表 dept_id 归属。  
4. （可选）**sys_user_role**：为 admin 分配管理员角色（若库中已有角色）。  
5. **不插入**：duty_schedule、attendance_record、attendance_result、attendance_device，由后续排班与考勤操作产生。
